🚘 Mercedes-Benz Website
Luxury Automotive Web Experience

A visually rich and elegant Mercedes-Benz themed website designed to showcase luxury vehicles with a premium look and smooth user experience.

🌐 Live Demo: https://benzcar.netlify.app/

✨ Project Overview

This project recreates the luxury feel of the Mercedes-Benz brand using modern web design principles.
It focuses on clean layouts, high-quality visuals, and a smooth browsing experience that reflects premium automotive standards.

🛠️ Tech Stack

HTML5

CSS3

JavaScript

Responsive Web Design

🌟 Key Features

✔ Premium UI inspired by luxury automotive branding
✔ Smooth scrolling and clean layouts
✔ Responsive design for all devices
✔ Modern typography and visuals

🎯 Project Goal

The goal of this project is to:

Practice brand-focused UI design

Build a luxury product showcase

Strengthen frontend development skills

Create a strong portfolio project

⚙️ Getting Started

To run the project locally:

git clone <repository-url>
cd mercedes-benz
open index.html

The website is deployed using Netlify for fast and reliable performance.
